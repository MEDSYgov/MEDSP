# منصة مديرية التخطيط والإحصاء

منصة تقارير تفاعلية لوزارة الطوارئ وإدارة الكوارث — الجمهورية العربية السورية.

بُنيت بهوية الوزارة البصرية الرسمية: ألوان وخطوط وعناصر مأخوذة من الدليل الإرشادي لاستخدام الهوية البصرية.

---

## التشغيل محلياً

يتطلب Node.js إصدار 20 أو أحدث. انسخ `.env.example` باسم `.env.local` وضع فيه القيم.

```bash
npm install
npm run dev
```

ثم افتح العنوان الذي يظهر في الطرفية (عادة `http://localhost:5173`).

لاختبار نسخة الإنتاج محلياً:

```bash
npm run build
npm run preview
```

## الرفع على GitHub ثم Vercel

### أولاً: GitHub

1. أنشئ مستودعاً جديداً فارغاً على GitHub (بدون README وبدون gitignore).
2. من داخل مجلد المشروع:

```bash
git init
git add .
git commit -m "الهيكل الأساسي للمنصة"
git branch -M main
git remote add origin <رابط-المستودع>
git push -u origin main
```

### ثانياً: Vercel

1. من لوحة Vercel اختر **Add New** ثم **Project**.
2. اختر المستودع الذي رفعته.
3. ستكتشف Vercel الإعدادات تلقائياً. تأكد فقط من أنها:
   - **Framework Preset:** Vite
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
4. اضغط **Deploy**.

يحتاج المشروع متغيرَي بيئة في إعدادات Vercel (Settings → Environment Variables): `SUPABASE_URL` و`SUPABASE_KEY`.

للتشغيل على سيرفر الوزارة انظر [DEPLOY.md](DEPLOY.md).

### إن ظهر خطأ

- **فشل التثبيت:** تأكد أن Node على Vercel هو 20 أو أحدث من إعدادات المشروع.
- **صفحة بيضاء بعد النشر:** تأكد أن مجلد الإخراج هو `dist` وليس غيره.
- **الخطوط لا تظهر:** تأكد أن مجلد `public/fonts` مرفوع كاملاً إلى GitHub.

## إضافة تصنيف جديد

افتح `src/data/categories.js` وأضف عنصراً:

```js
{
  id: 'earthquakes',
  name: 'الزلازل',
  summary: 'وصف مختصر لما يغطيه التقرير.',
}
```

لا حاجة لتعديل أي ملف آخر.

## تحديث البيانات شهرياً

1. صدّر الملف الشهري من منصة الوزارة
2. ضعه في مجلد `data/` بصيغة `Month_Year.xlsx` (مثال: `September_2026.xlsx`)، واحذف ملف الشهر السابق
3. نفّذ:

```bash
npm run data
```

4. ادفع التغييرات إلى GitHub — تعيد Vercel النشر تلقائياً

الملف المرجعي `data/syr_admin_boundaries.xlsx` يربط ترميز المنطقة بالإحداثيات، ولا يُحذف.

بعد اعتماد هيكل التقرير، يُبنى قالب جدول الإكسل المطابق له، وتُربط آلية الرفع والتحديث.
